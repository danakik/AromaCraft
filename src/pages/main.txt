AromaCraft is a web-based application designed to help users create and manage their own custom fragrances. 
The application provides a user-friendly interface for selecting and combining various scents to create unique fragrance blends. 
Users can save their favorite blends, share them with others, and explore new fragrance combinations.
AromaCraft aims to make the art of fragrance creation accessible and enjoyable for everyone.

Technologies used:
- HTML, CSS, TypeScript for the frontend
- React.js for building the user interface
- Node.js and Express.js for the backend server
- REST API for communication between the frontend and backend
